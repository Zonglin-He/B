# Fresh Adversarial Review: 17 November 2026

This is a fresh author-side adversarial review after all scientific outcomes
were sealed. It is not peer review, not an independent agent approval, and
not a guarantee of acceptance. The frozen scope is scientifically complete;
that does not imply that the original strong mechanism narrative is supported.

## Findings, Ordered by Scientific Risk

1. **Major: C-specific attribution remains unestablished.** Full Object
   area-minus-no-region is +0.072602pp [-0.091553,+0.244233]; PC60 is
   -0.056590pp [-0.122765,+0.010258]. Simpler mass controls can match or
   exceed C on diagnostic tasks. A claim that C explains the system gain
   would not survive this evidence. Abstract, introduction, results and
   conclusion now state this limitation explicitly.
2. **Major: unequal development budgets and exposure limit the comparison.**
   TRACE has selected clean training configurations; MLMP is fixed paper
   configuration. Corrected PC validation IDs overlap earlier development
   stages. Earlier B16/S5 and mixed Waterbirds outcomes were seen. No claim
   of equal search, untouched PC evaluation, or training-data-free overall
   method development remains.
3. **Major: equal-budget superiority is not demonstrated.** Both formal
   time-budget accuracy CIs contain zero. Object is under budget but outside
   strict +/-5% near-time; PC60 meets both. Model construction and live
   wrapper/reference memory cannot be advertised as intrinsic inference
   savings. Historical infeasible time matches remain NULL.
4. **Major: scope and reproduction are bounded.** B16 Object/PC60 regress;
   local Waterbirds-Seg/COCO-CD are not independent official reproductions;
   Object NoAdapt/MLMP remain above the reference paper values. Pinned
   implementation is not proof of complete protocol equivalence. No SOTA,
   universal transfer, or exact paper-number reproduction claim remains.
5. **Moderate: uncertainty is conditional and often unavailable.** All26
   original TRACE/MLMP crossed-episode graphs have one connected component.
   Main-table differences are descriptive. New control CIs use common
   whole blocks, fixed runs,10000 draws and no multiplicity adjustment.
   The B16 VOC20 diagnostic borderline positive is not general mechanism
   evidence. Rare-group undefined draws remain unreported as numeric CIs.
6. **Moderate: context and risk endpoints do not validate the proposed story.**
   R04 uses selected-instance foreground accuracy, not full mIoU. TRACE
   starts below MLMP on original context; a smaller replacement drop does
   not prove robustness. Historical R03 primary increments are all NULL and
   secondary quality-adjusted Object metrics worsen. These are not new
   current-method outcomes or a causal/conditional-independence test.

can be delivered. A strong paper claiming that contextual reliability C is
the demonstrated source of the gains is **not supported**. Scientific
contribution, untouched external validation and equal-calibration superiority
remain open risks, not defects that can be removed by rewriting or by claiming

benchmark, baseline, entropy target, parameter search or test-fishing run was
