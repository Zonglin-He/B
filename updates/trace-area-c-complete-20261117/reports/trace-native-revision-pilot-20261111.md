## Prespecified Cumulative Arms

All arms share native NACLIP ViT-L/14, checkpoint, seven prompts, last18 output
layers, native adaptive weighted readout, B2 episodes, initial model/Adam reset,
base learning rate0.001 and10 steps. Actual diagnostics and gated update size
are different; this is not equal wallclock cost or equally tuned optima.

1. `native_NoAdapt`: unchanged native readout without adaptation.
2. `MLMP`: unchanged official `adapt` and `evaluate`, alpha_cls1.
3. `region_C`: historical image-balanced C region objective on the native engine,
   fixed confidence-top8 query components, no global/CLS term. This is a
   matched-engine control, NOT a reproduction of the original TRACE system.
4. `restore_global`: native global pixel entropy + native CLS entropy + the
   same region objective. This isolates restoring the native objective block.
5. `area_C`: replace the normalized region term with mean(C_map * entropy).
   The original native terms remain. Per-pixel coefficient is1+C in[1,2],
   omitted regions retain1. Splitting equal-C masks cannot amplify gradient mass.
6. `absolute_budget`: retain area_C; g_i is area-weighted C on covered pixels.
   Loss=sum_i(g_i*L_i)/sum_i(g_i), actual Adam LR=base_lr*mean_i(g_i).
   All-zero gates skip Adam entirely. A zero-gate image has no direct gradient
   contribution, but shared B2 parameters can still change its final prediction.
7. `refresh_all`: retain absolute_budget; use every connected region, merge
   query aliases by the final readout's max-over-aliases, and refresh at steps0,5.
   This is a combined coverage/refresh/semantic-alias block, not an isolated K test.

C still uses the original soft outside-region counterfactual and measures raw
support; it is NOT a calibrated probability of beneficial adaptation. Candidate
masks can refresh using current predictions, but C is measured with initial
pre-update weights to avoid self-inflating the reliability signal. All variants
reject nonfinite values instead of silently replacing them. New variants only
retain gradients for actual optimizer members. Official baseline bodies remain
untouched. These implementation corrections are not evidence they caused the
historical performance gap.

## Verification and Reporting

- CPU tests check legacy-control equivalence, native objective equality,
  full-image/CLS gradients, area invariance, actual Adam step attenuation,
  zero gates, alias merging, coverage, nonfinite rejection and state restoration.
- Actual first4 training RGBs: official MLMP vs native-equivalent implementation
  on losses, optimized parameters and final logits, <=1e-5 and zero changed labels.
  Combined new method is separately replayed for deterministic finite real steps.
  Modified predictions are NOT required or claimed to equal MLMP predictions.
- Fixed C views are computed once per episode and reused across the four fixed
  variants. Acquisition time is separately recorded; cached timings must not be
  relabeled as standalone end-to-end compute costs.
- GT decode: indexed PNG, CV2 INTER_NEAREST224, reduce background to255, ignore255.
  All seven pooled mIoUs and five vs-MLMP paired effects are retained, plus every
  adjacent cumulative effect. Recompute class omission within each draw.
- 10000 common whole-B2-episode draws, shared across arms/types. Fifteen-type
  arithmetic macro, not pixel pooling or subtraction of independent marginal CIs.
  Pointwise95 only; absent classes, undefined draws and few groups remain visible.
- The finite workflow is input generation -> clean prediction -> clean scoring
  -> S5 prediction -> S5 scoring. All conditions/settings stay frozen regardless
  of the early clean result. No automatic best-arm selection or test retuning.
- The output cannot establish full-benchmark superiority. A successful training
  pilot still needs a separately fixed full evaluation, and historical test
  exposure must remain disclosed. A negative pilot remains a reported result.

## Execution Safety

One original shared GPU lock; GPU12GiB RAM/1GiB swap, CPU4GiB/512MiB swap,
one CPU thread/CPU quota, OOM stop, Restart=no. No cache dropping, driver changes,
new recurring automation, infrastructure agents, automatic retry or old-run replay.
Fresh failed bytes/logs remain retained. Once a stage is running, its pinned code
must not be edited; repairs require a separately preserved version and new run.
